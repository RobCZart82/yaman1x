# Research history

The earlier local workspace used the working name YamANIx. YamAN1x and the
repository slug `yaman1x` were confirmed on 2026-10-26. Technical symbol names,
trace markers, protocol bytes and archived patch files retain their earlier
spelling to preserve reproducibility.

Selected narrative reports and JSON statistics are retained here. Their test
counts describe the larger local research workspace at that time: eight own
project groups plus two upstream tests using local Yamaha images. The clean
repository retains the eight own groups and adds a repository audit.

Raw logs, original ROM/program/table images, patch banks, bank-name exports,
PDFs, compiled products and reports containing local absolute paths are not
part of this snapshot. Historical references to these local artifacts describe
external research inputs/results; they are not download links in this repo.
